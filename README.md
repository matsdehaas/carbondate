# CarbonDate

**Java · Android Studio · Firebase · XML**  
**Course:** University of Alberta · CMPUT 301 Software Engineering  
**Project type:** Team Android project

## Overview

Android event lottery system supporting user accounts, event creation and discovery, waitlists, invitations, notifications, participant selection and QR-code screens. The project uses Firebase Authentication and Cloud Firestore.

## Repository contents

- `app/src/main/java/com/example/carbon/` — application source.
- `app/src/main/res/` — layouts, menus and resources.
- `app/src/test/` — included test sources.
- Interactive Figma prototype: https://www.figma.com/proto/WqP0pttyIvMwm1zg607Khp/Carbon

## Running

Open the project in Android Studio, install the appropriate Android SDK and Gradle dependencies, and configure the services required by the original implementation. Build/run behavior has not been verified in the current environment.

**Configuration:** `local.properties`, any `google-services.json`, private keys, and user data are deliberately excluded. Supply your own authorized Firebase project configuration where required. Do not commit credentials or personal information.
